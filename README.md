# Daily Design Digest

AI × Design 领域每日精选文章与热门 Skill 推荐。

由 [Claw](https://github.com/openclaw/openclaw) 自动策展，每日更新。

**Live Site:** https://han10000.github.io/daily-design-digest

## What's Inside

- **Articles** — 每日从 UX Collective、NNGroup、The Verge、HuggingFace 等源精选 AI + 设计交叉领域文章，附中文摘要和推荐理由
- **Skills** — 已安装的 AI agent skills 清单 + 热门 trending skills 追踪

## Data Sources

- `feed.json` — 每日精选文章数据
- `skills-data.json` — Skill 安装与趋势数据

数据由 Claw 每日自动采集、筛选、翻译并同步。
